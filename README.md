# G10T English Study Assistant

本地优先的英语学习闭环：收集材料 → 间隔重复复习 → 写作输出 → 测试评估 → 统计复盘。
零依赖、无构建，Node 单进程同时提供页面与 JSON API。

## 快速开始

```bash
# 需要 Node 24+（依赖内置 node:sqlite）
node server.js
# 或双击 start.bat
```

浏览器访问 http://127.0.0.1:5173 。首次启动自动建库并写入示例数据。
可用 `HOST` / `PORT` 覆盖监听地址。

## 未做或简化

- **主动延期**：口语练习（录音/ASR/发音评分）未做；"发帖模式"只是按长度与语域练习，不真的发到社交平台；无提醒或定时任务。
- **简化实现**：词库仅 60 个种子词（6 段 ×10），词汇量估算固定 ±500，只作参考基线；无 Key 时写作反馈为本地启发式（词数、衔接词、词汇多样性、平均句长、已学表达命中），非真正语法分析；复习只有"看语境回忆 + 自评"，无中→英产出、拼写或听写；材料释义无前端编辑表单，只能调 `PATCH /api/materials/:id`；统计为静态 CSS/SVG，无交互筛选与导出；搜索为 SQL `LIKE`。
- **工程化缺失**：无自动化测试，仅 API 端到端脚本 + 三轮浏览器逐页验证；无安装包或独立 exe，依赖 Node 24；API Key 明文存于本地 SQLite `settings` 表；无账号、多设备同步、云备份，响应式仅到 760px。

## 技术方案

- **总体**：本地 Web 应用，Node 单进程 + 原生 HTTP，无 npm 依赖、无构建、无框架。
- **数据层 `db.js`**：`node:sqlite` 的 `DatabaseSync`，WAL 模式；11 张表（`settings / materials / cards / review_logs / prompts / writings / tests / test_items / snapshots / loop_days / words`）；软删除保留历史，`norm` 唯一约束做重复检测；所有日期按 `localDay(ts, 4)` 计算。
- **服务层 `server.js`**：原生路由 + 静态 MIME 映射 + SPA fallback；27 个 API 端点覆盖收集、补全、复习、写作、测试、统计、设置、备份、导出；AI 走 OpenAI 兼容 `/chat/completions`（`response_format: json_object`，60s 超时），失败或无 Key 自动降级本地规则；备份为每日首启复制 DB 保留 30 份，导出落 `data/exports/`。
- **算法**：间隔重复 rating 1 重置并降 ease、2 小幅降、3 乘 ease、4 乘 ease×1.3；主动使用率 = 28 天窗口内已学材料真正写进文章的比例（分母 <10 显示"—"）；综合 CEFR 取词汇与写作两维较低者。
- **前端 `app.js`**：原生 ES Modules + hash 路由（7 个视图），无虚拟 DOM，整体重渲染；`app.css` 为印刷品风格设计系统（纸张色、硬阴影、衬线标题、编号导航）；`core.js` 统一封装 fetch、toast、转义与文本相似度。

## 验证与已知问题

已验证：全 API 流程端到端通过；7 个页面浏览器渲染无报错；干净解压副本可首次启动并自动建库。
已知环境问题：沙箱公网预览网关持续报 `no healthy upstream`，但应用本身 IPv4/IPv6 及容器内代理均返回 200，本地运行不受影响。
